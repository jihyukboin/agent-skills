# IndexNow FAQ

[Source: Naver Search Advisor](https://searchadvisor.naver.com/guide/indexnow-faq)

### Q. Is there a limit to the number of API requests?
There is no limit to the total number of requests; limits apply if there are a large number of requests at once.

### Q. How do I know if a search engine successfully received my request?
If the request was successfully received, the IndexNow API returns an HTTP 200 OK code. However, we do not guarantee that the documents included in the request will be indexed.

### Q. Does IndexNow replace collection requests, RSS, and sitemap submissions within Search Advisor?
No, IndexNow is great for quickly notifying search engines that you have new information, and at the same time spreading the word to other search engines.
You can use Search Advisor Webmaster Tool's crawl request, RSS, or sitemap submission as appropriate.

### Q. Can you also notify me when a website page has been changed to return a 404, 301 or 302 HTTP Code?
Yes, even in this case, you can notify us of changed information through IndexNow.

### Q. Now I know about IndexNow. Should previously changed URLs also be requested through the IndexNow API?
No, you should only publish URLs that have been added since you started using IndexNow.

### Q. Can I know more about IndexNow?
Please refer to IndexNow [official document](https://www.indexnow.org/ko_kr/index) and [FAQ](https://www.indexnow.org/ko_kr/faq).
