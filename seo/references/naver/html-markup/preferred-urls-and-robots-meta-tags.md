# Preferred URLs and robots meta tags

[Source: Naver Search Advisor](https://searchadvisor.naver.com/guide/markup-structure)

#### Preferred URL (=Representative URL)
Use the \<link\> tag within the \<head\> tag of the HTML document.

```
<head>
<link rel="canonical" href="http://www.mysite.com/article/article1.html">
</head>
```

If the same content can be expressed through multiple URLs, specify the most preferred representative URL. For example, if the three URLs below show the same page, it would be a good idea to specify http://www.mysite.com/article/article1.html as the preferred URL. Additionally, when expressing URLs, absolute paths must be used, not relative paths.

```
http://www.mysite.com/article/article1.html
http://www.mysite.com/article/article1.html?type=1&code=a
http://www.mysite.com/article/article1.html?type=2&code=b
```

For the site's main page, it is better to use HTTP redirect rather than specifying the preferred URL using the link tag to avoid confusing users visiting the site. For more information, see our Search Engine Optimization Guide.

#### robot meta tag
Use the \<meta\> tag within the \<head\> tag of the HTML document.

```
<head>
<meta name="robots" content="명령어">
</head>
```

Robot meta tags are information that allows you to control whether or not crawlers can access each page.
If you use noindex in a command, the page will be excluded from search results, and if you use nofollow, you can set crawlers not to collect links within that page.
If nosourceinfo is used in the command, the source description automatically generated by AI for the site will not be provided.

* Processed for indexing, links within the page are not collected
```
<head>
<meta name="robots" content="index,nofollow">
</head>
```
* Exclude from indexing, collect links within pages
```
<head>
<meta name="robots" content="noindex,follow">
</head>
```
* Excluded from indexing, links within pages not collected
```
<head>
<meta name="robots" content="noindex,nofollow">
</head>
```

* Excluding site source description
```
<head>
<meta name="robots" content="nosourceinfo">
</head>
```


If there are no special restrictions regarding crawlers, we recommend deleting the robot meta tag or setting it to the default settings of index and follow as shown below to prevent web pages from being excluded from search results.

```
<head>
<meta name="robots" content="index,follow">
</head>
```

For reference, when the robot interprets the tag, the meta tag may not be reflected properly if the page consists only of a redirect function that moves to a different URL.
In this case, we recommend setting the same settings for all redirect target pages.
