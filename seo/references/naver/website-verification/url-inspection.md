# URL inspection

[Source: Naver Search Advisor](https://searchadvisor.naver.com/guide/url-inspection)

URL inspection provided by Webmaster Tools is a tool used by Naver crawler to collect site content and provide index information.
In addition, we provide meta and SEO information for URL documents to guide you on areas where optimization is lacking.
Index/Meta/SEO Each item is exposed separately into three tables, and when clicked, detailed information is displayed at the bottom.

### index
Provides URL status (StatusCode), collection status, indexability, and indexability.
Through the index table, you can check whether your URL has been collected and, if so, whether it can be exposed in searches (indexed or not).
The icon on the right displays the document status (indexed, collected, or uncollected) in color.
![image](https://searchadvisor-phinf.pstatic.net/MjAyMjEwMjVfNTAg/MDAxNjY2Njg1NzA5NDA1.mQvoDYa9ytQaYXbucy9Q9xCxvv-gg59jluPzx8TnLQsg.R0XHTg7dh8mBpBDhtXFi6Y5CUGfolyOg4SmQhktvpgQg.PNG/url-inspection-2.PNG)



### Meta
Provides meta information embedded in HTML. Please check the results and correct any problems.
The icon on the right indicates whether the title and description can be extracted.
![image](https://searchadvisor-phinf.pstatic.net/MjAyMjEwMjVfMTk4/MDAxNjY2Njg1NzE0ODcw.dgDKa__BFw6B0htdkjYE9M2VTpRbYyXqfktd6Lbvs58g.u_tMbNaCq7y5obHXJYBenMZgBp8ODwcTXdmNMlARTVEg.PNG/url-inspection-3.PNG)


### SEO
We identify and provide elements that require search engine optimization.
Please check and correct the factors that affect crawling and indexing.
The icons on the right and the color of each SEO element indicate SEO importance (must be modified, good to modify, good to maintain) in color.
