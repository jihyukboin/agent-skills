# Introduction to IndexNow

[Source: Naver Search Advisor](https://searchadvisor.naver.com/guide/indexnow-about)

Search Advisor supports [IndexNow protocol](https://www.indexnow.org/ko_kr/).

Through IndexNow, you can notify Naver Search of newly created pages or pages that have been updated or deleted. When you announce changes to your website through IndexNow, you don't have to wait for crawlers to visit your website. Additionally, updated page information is shared with other search companies.

One thing to note is that the IndexNow protocol serves to quickly notify search engines of website changes, but does not guarantee the indexing of web pages.

To use the IndexNow protocol, you must use an API using HTTP and Json data.
