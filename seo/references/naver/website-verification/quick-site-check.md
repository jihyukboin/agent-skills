# Quick site check

[Source: Naver Search Advisor](https://searchadvisor.naver.com/guide/diagnose-site)

[Simple site check](https://searchadvisor.naver.com/tools/sitecheck) provided by Search Advisor is a diagnostic tool that allows you to check whether a site is optimized for search (SEO) before registering it in Webmaster Tools. If it is difficult to develop the site yourself, one option is to use a good company that provides SEO-compliant templates. Before building a site, receive the company's portfolio and run a simple check. You can check in real time whether you are complying with search optimization.

![Simple site check](https://searchadvisor-phinf.pstatic.net/MjAxOTEwMjRfMjcw/MDAxNTcxODk1NDM0NzMx.NAE60cFrqXlzLKUITkApYmn4Bt4EA7cNJl3HDHrjFqIg.mJnG9kWBeUYJaO68-Af1oqt25klLuJx7WEQm-zy5itYg.PNG/diagnose-site-1.png)

When you run a simple site check, it visits the main page of the site in real time, analyzes the HTML, and shows the results. Refer to the simple check result report and check with the site development manager.

### crawler
###### Can the Naver crawler access the site properly?
###### Can Naver crawler collect site information? (robots.txt)
###### Are the site title and site description set? (title, description meta tags)
###### Can Naver Search reflect your site in the search? (no noindex setting)
###### Are the site title and site description too long? (We recommend that you keep the title within 40 characters and the description within 80 characters.)
###### Are there a lot of repeated words in the site title and site description?
###### Are there any keywords that are unrelated to the site content?
###### Have you submitted rss and sitemap through Webmaster Tools to ensure that the generated content is reflected in searches without omission?

### content
###### Is the site consistently maintained?
###### Are there any spam posts on bulletin boards, etc.?
###### Are you posting your own content related to the topic on the site?
