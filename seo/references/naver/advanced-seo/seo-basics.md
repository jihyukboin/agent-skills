# SEO basics

[Source: Naver Search Advisor](https://searchadvisor.naver.com/guide/seo-help)

Optimization should aim to improve the site and user experience in a way that is beneficial to website users.
Naver crawlers are also users, and through search engine optimization (SEO), you can help Naver crawlers better understand the content of your site.
Content with good search engine optimization (SEO) is easy to analyze by Naver crawlers and helps provide better content in search results.


### `<title>` element not found
You need to create an accurate and unique title that represents the topic of your content.
The `<title>` element tells Naver crawlers what the topic of the page is.
Add a `<title>` element within the HTML document `<head>` element to create precise, unique title text that represents the topic of the page.


### `<meta name="description">` description missing
The meta description tag provides a summary of the page content.
The page's meta description tag is written as a summary of the page consisting of several sentences. It is also used as a snippet in search results, so it is a good idea to enter a summary for each page.
The meta description tag is inside the HTML document `<head>` element.


### Two or more `<title>` elements found
`<title>` Elements must have an accurate and unique title that represents the topic of the content.
If two or more `<title>` elements are written in an HTML document, the Naver crawler must analyze which `<title>` matches the page content topic.
In this case, crawlers have to do extra work and may classify the page as bad.


### Found multiple web documents with the same title in the `<title>` element
`<title>` Elements must have an accurate and unique title that represents the topic of the content.
If multiple pages on a site have the same `<title>`, the crawler must analyze which page is most suitable for `<title>`.
These `<title>` elements do not fit the content topic, and it is not clear which pages should be exposed as search results.
Please aim to create unique `<title>` elements for each page.


### `<title>` element text length needs to be checked
The `<title>` element represents the page content title. It is not right to write the title as a very long text.


### The same description was found in the `<meta name="description">` tag.
Just as the `<title>` element should have a precise and unique title that represents the topic of the content, the meta description should also be a unique summary.
If the same meta description exists on multiple pages, the Naver crawler may judge the content as meaningless or classify it as a duplicate document, which may affect exposure.


### Two or more `<H1>` elements found
`<H1>` elements are used as subheadings representing page content, so if two or more elements are found in an HTML document, the structure becomes difficult for Naver crawlers to understand.


### Alt attribute missing
If the content image has a description (Alt) attribute, it is a structure that is easy for Naver crawlers to understand.
You can interpret the topic of page content and images well.
